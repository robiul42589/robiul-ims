# Robiul - Information Management System (রোবিউল - ইনফরমেশন ম্যানেজমেন্ট সিস্টেম)

একটি পূর্ণাঙ্গ, আধুনিক ও মার্জিত ইনফরমেশন ম্যানেজমেন্ট সিস্টেম (IMS) ওয়েব অ্যাপ্লিকেশন। এখানে ব্যবহারকারী তার ব্যক্তিগত তথ্য, পরিবারের সদস্য বিবরণী, শিক্ষাগত যোগ্যতা ও কারিগরি দক্ষতা, জমির খতিয়ান ও দাগসহ সকল স্থাবর সম্পদ, আর্থিক দায় ও ঋণ, এবং চাকুরীর পূর্বাপর ইতিহাস সুন্দরভাবে পরিচালনা, দেখতে, যুক্ত করতে, সংশোধন করতে ও মুছে ফেলতে পারেন।

---

## 🌟 মূল বৈশিষ্ট্যসমূহ (Key Features)

1. **ড্যাশবোর্ড (Dashboard):**
   - লাইভ ডিজিটাল ঘড়ি (Digital Clock) ও বাংলা ক্যালেন্ডার উইজেট (Interactive Calendar)।
   - সকল মডিউলের রিয়েল-টাইম পরিসংখ্যান কার্ড।
   - দ্রুত তথ্য সংযোজন ও সাম্প্রতিক কার্যক্রমের সারাংশ।

2. **পরিবার পরিচিতি (Family Profile):**
   - পরিবারের সদস্যদের পূর্ণাঙ্গ তথ্য (বাংলা ও ইংরেজিতে নাম, জন্ম তারিখ, পিতা-মাতার নাম, জন্ম নিবন্ধন / এনআইডি নম্বর, রক্তের গ্রুপ, পেশা এবং পূর্ণাঙ্গ ঠিকানা)।
   - ছবি আপলোড ও প্রিভিউ সুবিধা।
   - সম্পূর্ণ প্রস্থের (Full-Width) লাইন-বাই-লাইন পরিচ্ছন্ন লিস্ট ভিউ।

3. **শিক্ষা ও দক্ষতা (Education & Skills):**
   - শিক্ষাগত যোগ্যতা (ডিগ্রি, বিভাগ, শিক্ষা প্রতিষ্ঠান, শিক্ষাবর্ষ, ফলাফল ও সার্টিফিকেট সংযুক্তি)।
   - পেশাগত ও কারিগরি দক্ষতা (দক্ষতার নাম, লেভেল, অভিজ্ঞতা, প্রতিষ্ঠান ও সনদপত্র আপলোড)।

4. **সম্পদ বিবরণী (Asset & Land Records):**
   - জমির খতিয়ান বিবরণী (মৌজা, জেএল নং, খতিয়ান নং, ভূমি অফিস, উপজেলা ও জেলা)।
   - মালিকানা ও হিস্যা বিবরণ।
   - দাগ ও প্লট বিবরণী (দাগ নং, ভূমির শ্রেণী, জমির পরিমাণ শতক)।
   - প্রাক্কলিত আর্থিক মূল্য এবং মূল দলিল/খতিয়ান স্ক্যান কপি আপলোড।

5. **দায় সমূহ (Liabilities & Debt Management):**
   - দায়ের কারণ, পাওনাদার ব্যক্তি/ব্যাংকের নাম, ঋণের পরিমাণ, গ্রহণের তারিখ, সম্ভাব্য পরিশোধের তারিখ এবং অবশিষ্ট পাওনার হিসাব।
   - চলমান ও পরিশোধিত স্ট্যাটাস ট্র্যাকিং।

6. **চাকুরীর ইতিহাস (Employment History):**
   - প্রতিষ্ঠানের নাম, পদবী, যোগদানের তারিখ, অবসরের তারিখ, দায়িত্ব এবং বর্তমান চাকুরীর লাইভ স্ট্যাটাস।
   - নিয়োগপত্র / ছাড়পত্র ডকুমেন্ট আপলোড।

7. **রিপোর্ট ও প্রিন্ট (Reports & Printing):**
   - পূর্ণাঙ্গ জীবনবৃত্তান্ত ও সম্পদ-দায়ের প্রিন্ট-রেডি প্রতিবেদন (Print / PDF Export)।

8. **ক্লাউড সিঙ্ক ও ব্যাকআপ (Cloud Sync & Data Center):**
   - এক ক্লিকে সম্পূর্ণ ডাটাবেজ JSON ব্যাকআপ ডাউনলোড।
   - যে কোনো ব্যাকআপ ফাইল আপলোড করে সম্পূর্ণ তথ্য রিস্টোর করার সুবিধা।
   - সম্পূর্ণ সোর্স কোড (.ZIP) ডাউনলোড অপশন।

9. **ডার্ক ও লাইট মুড (Dark & Light Mode):**
   - সাইডবার, হেডার এবং প্রতিটি মডিউলে নির্বিঘ্ন ডার্ক এবং লাইট থিম সাপোর্ট।

10. **স্মার্ট এআই সহকারী (Gemini AI Assistant):**
    - Google Gemini AI সংযুক্ত স্মার্ট হেল্পার, যা অ্যাকাউন্টের যে কোনো তথ্যের উপর ভিত্তি করে তাৎক্ষণিক উত্তর দেয়।

## 🛠️ প্রযুক্তি (Tech Stack)

- **Frontend:** React 19, TypeScript, Tailwind CSS v4, Lucide React Icons, Motion
- **Backend / API:** Node.js, Express, Vite Middleware, @google/genai SDK
- **Storage:** Browser LocalStorage with Encryption + JSON Data Export/Import

## 🚀 লোকাল মেশিনে চালানোর নিয়ম (Getting Started)

### ১. ডিপেন্ডেন্সি ইনস্টল করুন:
```bash
npm install
```

### ২. এনভায়রনমেন্ট ভ্যারিয়েবল সেটআপ (ঐচ্ছিক - Gemini AI এর জন্য):
`.env.example` ফাইলটি কপি করে `.env` নামে সেভ করুন:
```bash
cp .env.example .env
```
প্রয়োজনে আপনার `GEMINI_API_KEY` প্রদান করুন।

### ৩. ডেভেলপমেন্ট সার্ভার চালু করুন:
```bash
npm run dev
```
ব্রাউজারে ভিজিট করুন: `http://localhost:3000`

### ৪. প্রোডাকশন বিল্ড তৈরি করতে:
```bash
npm run build
npm start
```
